Installer l'application

Ajoutez Suivi de Budget à votre écran d'accueil : elle s'ouvrira en plein écran, comme une application, et gardera vos données sur l'appareil.

Dans Safari, touchez le bouton Partager en bas de l'écran, puis Sur l'écran d'accueil.

Ouvrez le menu de votre navigateur, puis choisissez Installer l'application ou Ajouter à l'écran d'accueil.

Une fois installée, l'application a besoin d'être ouverte au moins une fois avec du réseau après chaque mise à jour.

Utiliser mon propre projet Firebase

Vos données ne transiteront que par votre propre projet, entièrement isolé de celui fourni par défaut. Il vous faut environ 5 minutes pour le créer une seule fois.

  1. Allez sur console.firebase.google.com, créez un projet (gratuit, sans carte bancaire)
  2. Dans le projet → Firestore Database → Créer une base → mode production
  3. Dans Authentication → Sign-in method → activez Anonyme
  4. Dans Paramètres du projet → ajoutez une appli Web (icône </>) → copiez le bloc firebaseConfig
  5. Collez ce bloc ci-dessous
